- 気づき・疑問：
  - 講義の「入力の量と使えることは別」「コストは別問題」が数字で見えた．正答は全方式で同じだったので，この規模ではロストインザミドルは観測できず，差が出たのはトークン数と時間だけだった．全文投入が 2.4 秒で返ったのに対し RAG が 13 秒かかったのは，埋め込み API の呼び出しとツール往復（モデル応答 2 回）の分で，講義で言われた「段階が増える分の時間」そのものだった
  - Tree は「目次の先頭文」という人向けの構造をそのまま LLM に見せるので，どのページを選んだかの理由が trace から読める．一方で，章を 1 つ間違えると全部やり直しになるので，章タイトルが曖昧な資料では危ないと思う．Graph の `expanded` は共通用語でつながるだけなので「答えがあるとは限らない」という注意書きが，今回は seeds に答えがあったために確かめられなかった
  - 疑問：`[cost]` は生成 API だけで埋め込み分が入らないので，RAG の費用は実際にはもう少し高い．埋め込みの単価と回数（質問ごとに 1 回）を含めても全文投入より安い境界が，資料何ページくらいなのかを一度計算したい
